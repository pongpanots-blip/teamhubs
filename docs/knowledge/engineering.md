# Engineering Conventions

## Task readiness checklist

A task is ready when:

1. Acceptance criteria are written
2. Design is linked (Figma URL) when UI work is required
3. Blocking dependencies are marked done

## Status mapping

- `backlog` — not ready
- `ready` — readiness score >= 70
- `in_progress` — open PR or active work signals
- `blocked` — explicit blockers from analysis
- `done` — completed
