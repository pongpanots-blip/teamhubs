Design note. No dropdown/select anymore — the "Reading" button at the top is a plain link straight to the "All projects" picker page (try clicking it). Choosing a project there is what actually switches context, same as picking a card. Team settings (PM-only) moved to a small link next to Sign out. Nav labels stay in Kanit (renders Thai) — serif is reserved for the masthead, issue numbers, and eyebrows. Sidebar is full viewport height and fixed in place — scroll down to see the worklist run past the fold while the rail stays put. Overview is now a dashboard: 4 stat tiles (serif figures, so numbers get the same editorial weight as headlines), a status bar chart, and a burndown sparkline — the task table moved below as a "Worklist" section rather than being the whole page.
