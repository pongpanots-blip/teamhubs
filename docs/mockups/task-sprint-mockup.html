ฟีเจอร์ที่แนะนำให้เพิ่ม

ทำก่อน

Quick-add bar (⌘K)

สร้าง task ง่าย ๆ ได้ใน 1 บรรทัดโดยไม่ต้องเปิด Grill chat เต็มรูปแบบ — ลดแรงเสียดทานสำหรับงานเล็ก ๆ

ทำก่อน

Sprint capacity indicator

แสดง pts ที่ commit เทียบกับ capacity ของทีมแบบเรียลไทม์ ตอนลากการ์ดเข้า sprint กันไม่ให้ overcommit

ทำก่อน

Blocked-task banner บน board

งานที่ status = Blocked ควรเด้งเด่นบน sprint board ไม่ใช่ต้องเปิด task detail ถึงจะเห็น (ตอนนี้ engine มี blockedBy อยู่แล้วในหน้า detail)

ถัดไป

Bulk sprint assignment

เลือกหลาย task จาก backlog แล้ว commit เข้า sprint พร้อมกันทีเดียว แทนที่จะทำทีละใบ

ถัดไป

Burndown บนหน้า Sprint

ระบบมี /api/sprints/[id]/burndown อยู่แล้ว — เอามาวาดกราฟบนหน้า sprint list ให้ PM เห็น trend โดยไม่ต้องเข้า sprint เดียว

ถัดไป

@mention ในกล่องคอมเมนต์/decision log

เพิ่ม assignee หรือ mention เพื่อนร่วมทีมในช่อง decision log ให้แจ้งเตือนอัตโนมัติ แทนต้องบอกด้วยปาก

อนาคต

Auto-suggest assignee

แนะนำผู้รับผิดชอบจาก workload ปัจจุบัน + component ที่เคยทำ แทนที่ PM ต้องจำเองว่าใครว่าง

อนาคต

Sprint retro notes

ต่อจาก burndown — เก็บบันทึก retro ผูกกับ sprint แต่ละอันเพื่อย้อนดู pattern ของทีมข้ามหลาย sprint

อนาคต

Dependency graph view

เห็นความสัมพันธ์ dependsOn ทั้งหมดของ sprint เป็นกราฟ แทนที่ต้องไล่เปิดทีละ task detail
